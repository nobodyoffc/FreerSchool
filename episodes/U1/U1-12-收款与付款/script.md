## 目标

看完这一集，观众能够：
- 明白余额是由一张张钞票组成的：付款时整张花掉，多出来的作为一张新钞票找回给自己；
- 用"收款"把自己的 FID 和二维码给对方，可以带上金额；
- 用"支付"给别人转账，看懂"发送交易"页上的花费、付给（含找零）、交易费；
- 在收款页、付款页的"记录"里，以及"交易"里查看收支记录；
- 在"现金"里看到组成余额的每一张钞票。

## 核对依据

- 主页身份卡上点 CID/FID 文字，复制当前身份的 FID，提示"已复制"（`HomeActivity`，`copied`）
- 记录页的头像：收款记录显示付款人（`item_income_card`，`income_from_avatar`），付款记录显示收款人（`item_expense_card`，`expense_to_avatar`）
- 主页上方身份卡有三个数：钞票张数（`cash_tooltip` 现钞数量）、余额（`balance_tooltip` FCH数额）、币天（`cd_tooltip`）：`HomeActivity`
- 主页图标："收款"（`menu_receive` → `ReceiveActivity`）、"支付"（`menu_pay` → `PayActivity`）、"交易"（`menu_tx` → `TxActivity`）、"现金"（`menu_wallet`，图标 `menu_account` → `CashActivity`，页标题"钞票"）
- 收款页、付款页底部第二个按钮叫"记录"（`records`；Freer 工作区改动，原为"收入""已付"）：只有图标、没有文字标签，不影响录制
- "收款"页（标题"收款"）：身份卡；"出示给付款人"（`show_the_payer`）下是二维码；"金额"输入框。没填金额时二维码只是 FID；填了金额，二维码变成 `freecash:<FID>@1?value=<聪>`，对方用"支付"扫码，收款人和金额都自动填好（`PayActivity` 解析 freecash URI）。底部：清除、记录（`IncomeActivity`）、返回
- "付款"页（`PayActivity`，标题"付款"）：身份卡；"付给"下是收款人框（提示"收款人"），旁边有联系人和扫码图标；"金额"框。联系人图标打开"链上搜索FID"页（`SearchFidsOnChainActivity`，CHOOSE_ONE_RETURN，也能从联系人里选）。底部：清除、记录（`ExpenseActivity`）、扫描、付款、返回
- 付款时应用自动挑选钞票（`CashManager.getValidCashes` → `CashSelector`）：优先用新钞票，不用的不选，留住老钞票的币天
- "发送交易"页（`SendTxActivity`）：上面是要花掉的钞票；"付给:"下列出新钞票——付给对方的一张，和找回给自己的一张（找零由 `TxHandler.createTx` 自动加，`changeTo` 默认为发送者）；"总值"（F）、"交易费"（c）、"币天销毁"。默认费率 0.00001 F/KB（`DEFAULT_FEE_RATE`）
- 发送后提示"交易已发送，需1–5分钟确认"（`tx_sent`）
- "交易"页（`TxActivity`，标题"交易"）：每笔一张卡片，左付款人头像、右收款人头像，中间是输入输出张数和金额，有日期时间；可按时间、付款人、收款人排序。底部"创建"打开构建交易（U2-03，本集不讲）
- "钞票"页（`CashActivity`）：每张钞票显示金额（F）和币天（cd），交易ID、索引、最后时间；可按 FCH、CD 排序。底部的"重组"和"发送"（选钞票构建交易）放到 U2-03 讲
- 币天：花掉的钞票积累的币天在这笔交易里销毁（"发送交易"页的"币天销毁"），找零的新钞票币天从零开始

## 场景

### S1 [讲师] 开场

> 到现在，你已经多次收到和使用钞票了。
> 这一集，我们看看怎样收款、付款，查看收支记录。

### S2 [动画] 钞票与找零

标注：每句一步——①钱包里三张钞票，1 F、0.5 F、0.2 F，上方合计"余额 1.7 F"；②要付 0.3 F：1 F 整张飞出，变成两张新钞票，0.3 F 飞向收款人，0.7 F 飞回钱包，中间掉下一粒"交易费"

> 你的余额，不是账户里的一个数字，而是由你的所有钞票的面额加总来的。
> 付款时，钞票整张花掉，付给对方的部分变成对方的新钞票，多出来的变成一张新钞票找回给你。和现金找零一样。

### S3 [录屏] 收款

操作：主页停留，身份卡上的钞票张数、余额、币天可读 → 点身份卡上的 CID，提示"已复制" → 点"收款" → "收款"页，停留，二维码可读 → 点"金额"框，输入 0.1 → 收起键盘，二维码变化，停留 → 点底部第二个按钮"记录" → "收入"页，停留 → 返回 → 返回主页
标注：圈出三个数 @"三个数" 50,650,1230,780；点击 CID @5.04s 619,453；点击 收款 @11.06s 676,1429；圈出二维码 @"二维码" 50,910,1230,1990；点击 金额 @17.40s 157,2170；圈出带金额的二维码 @"对方扫码" 50,910,1230,2270；点击 记录 @24.02s 930,2470；圈出付款人 @"头像是付款人" 200,385,520,1295

> 主页头像下面有三个数，依次是钞票张数、余额和总币天。
> [5.00] 点击自己的FID或CID，就能复制你的FID，发给付款人即可。
> [10.42] 或者点"收款"，会显示你的 FID 的二维码，请付款人扫一下。
> [16.71] 也可以先填上金额，二维码里就带上了金额，对方扫码后不用再输入。
> [22.51] 下面的第二个按钮"记录"，点开是历史收款记录，头像是付款人。

### S4 [录屏] 付款

操作：主页点"支付" → "付款"页 → 点收款人框旁的联系人图标 → "链上搜索FID"页，点联系人图标 → 选择 cy_qqN8 → 回到"付款"页，收款人已填好 → 在"金额"框输入 0.1 → 收起键盘，停留 → 点底部"付款" → "发送交易"页，停留，让付给、总值、交易费可读 → 点发送 → 提示"交易已发送"，回到主页（发送后付款页自动关闭）→ 再点"支付" → 点底部第二个按钮"记录" → "支出"页，停留 → 返回 → 返回主页
标注：点击 支付 @23.53s 1009,1413；点击 联系人图标 @30.64s 928,1818；点击 联系人图标 @34.48s 930,2466；点击 引路人 @37.79s 806,518；点击 金额 @41.95s 192,2166；点击 付款 @51.66s 918,2498；圈出付给 @"两张新钞票" 50,1010,1230,1560；圈出总值 @"总值" 40,1570,680,1830；点击 发送 @63.20s 934,2455；点击 支付 @75.71s 1008,1467；点击 记录 @80.08s 535,2475；圈出收款人 @"头像是收款人" 840,385,1260,1765
剪辑：22.7-24.6，30.3-31.1，34.2-35.2，37.5-38.4，41.7-52.0，56.0-63.6，69.9-74.5，75.1-76.3，79.8-80.6，84.3-93.2

> [23.22] 点"支付"，从联系人里选引路人作为收款人，填上金额。
> 也可以点扫码图标，扫对方的收款二维码。
> [51.32] 点"付款"，这里是要发出的交易。
> 它花掉你的一张钞票，变成两张新钞票：一张给引路人，一张找回给你自己。
> 总值就是花掉的那张钞票，它比两张新钞票多出的一点，就是交易费。
> [62.91] 点发送，几分钟后就确认了。
> [75.17] 再点"支付"，点"记录"按钮，可以看到历史付款记录，头像是收款人。

### S5 [录屏] 收支记录

操作：主页点"交易" → "交易"页，停留 → 向下滑，看到更早的几笔 → 返回主页
标注：点击 交易 @8.69s 653,1013；圈出最新一笔 @"最新的" 30,385,1250,595；圈出付款人 @"左边" 200,385,360,2000；圈出收款人 @"右边" 1090,385,1250,2000；圈出中间 @"中间" 350,385,1080,2000
剪辑：0-9.3，13.4-23.2

> [8.38] 点"交易"，已确认的每一笔收支都在这里，最新的在最上面。
> 付款人在左边，第一收款人在右边，中间是时间、钞票数量和金额。
> [16.26] 往下翻，可以看到更早的交易。

### S6 [录屏] 钞票

操作：主页停留，"现金"上有红色标记 1 → 点"现金" → "钞票"页，停留，每张钞票的金额和币天可读，第一张有红点 → 返回主页
标注：圈出红色标记 @"红色" 1050,830,1170,945；点击 现金 @8.15s 998,1049；圈出钞票列表 @"每一张" 40,400,1240,1225；圈出找零 @"红点" 40,400,1240,600
剪辑：0-8.6，9.9-23.0

> "现金" 上有个红色的标记 1，表明收到一张新钞票。
> [7.93] 点"现金"，能看到组成余额的每一张钞票，第一张标记了红点的新钞票，就是刚才的找零。

### S7 [卡片] 要点

- 余额是所有钞票面额的加总
- 付款花掉整张钞票，多出的找零给自己
- 花掉的钞票的币天会清零
- 收付款记录都可以随时查看

> 记住这四点。
