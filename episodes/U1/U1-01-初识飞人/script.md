## 目标

看完这一集，观众能够：
- 知道领航员是谁：链上一个真实的身份，不是虚构人物；
- 用一两句话说出自由宇宙是什么，知道这门课怎么学；
- 知道去哪里查链上信息、下载应用：freecash.info 或 cid.cash（自由宇宙浏览器），freecash.org；
- 装好飞人和密库，给飞人设好密码，进入主页；
- 知道密码保护着本机所有私钥：忘了没人能找回，太简单会被破解。

## 核对依据

- 自由宇宙浏览器：freecash.info 与 cid.cash 是同一个网站，标题"自由宇宙"（`siteTitle`），即 FreeverseExplorer（`~/tomcat-9.0.73/webapps/ROOT`，"Freecash 链和自由宇宙登记信息的网页浏览器"）。菜单：首页、工具、开发者、兑换、下载（`constants/strings.js`）
- 网站"下载"页："Freeverse 系列应用与工具的最新版本，发布于 GitHub"；筛选 全部 / Android / macOS / 服务端与 SDK；"安装前请先验证"：Android 版 Freer、Safe、MyCoins 和 EasyQR 使用同一签名密钥；访问 GitHub 慢可用"历史版本"页的本站镜像
- 浏览器本身也是一个可下载的应用：`freeverse-release.json` 里 FreeverseExplorer，`os: web`，FreeverseExplorer.zip
- freecash.org：**待确认**（抓取时返回 521，内容未核对）。暂按 Freecash 官网写
- 打开飞人，先到"验证密码"页（`MainActivity` → `CheckPasswordActivity`，`check_password`），按钮：创建、清除、验证；第一次用要点"创建"进入"创建密码"页：输入"密码""确认密码"，至少 4 位（`MIN_PASSWORD_LENGTH`），按钮"创建"：`CreatePasswordActivity`
- 首次设好密码，自动随机创建一个身份并进入主页：`CreatePasswordActivity.bootstrapFirstIdentityAndLaunchHome`
- 新建的密码库不保存密码，也不保存密码哈希：随机生成数据密钥，用密码（Argon2id）加密后保存为 `dekCipher`，校验密码就是看能否解开它（`ConfigureManager.createConfigure`、`verifyPassword`）；按密码哈希命名的只是旧版密码库
- 密码不可显示："APP密码不可显示，请妥善保存"（`app_password_can_not_be_shown_please_keep_it_carefully`）；私钥用密码派生的密钥加密保存（Argon2id，见 U1-03 核对依据）
- 已有密码时："验证密码"页输入密码 → "选择身份"列表 → 点身份进入主页
- 主页功能（`activity_home.xml` 顺序）：待办、代码、通证、文件、新闻、秘密、现金、转换、工具、联系人、密信、广场、团队、房间、应用、服务、协议、凭据、对话、交易、收款、支付、验证码、刻写
- 密库：`~/AndroidStudioProjects/Safe`，versionName 2.4，应用名"密库"，首次打开同样"创建密码"

### S6 [动画] 一个密码，保护所有私钥

标注：手机里一排钥匙（私钥）→ 被同一把锁锁住，锁上写"你的密码"；密码不出手机，应用里也看不到；一把问号钥匙试锁：简单密码一下打开，复杂密码试不完；忘记密码：锁永远打不开

> 你安装打开飞人后，第一件事是设一个密码。
> 你在这部手机上的所有私钥，都用这个密码加密后本地保存。
> 你的密码只有你自己知道，手机上不保存密码，只保存用它加密过的数据。
> 所以，私钥和密码不会外泄，也无法找回，要做好备份。
