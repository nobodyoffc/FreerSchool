## 目标

看完这一集，观众能够：
- 说出 DOCK 和 DISK 是什么：DOCK 是消息服务器，你不在线时替你暂存消息；DISK 是文件服务器，保存你的文件；
- 明白为什么要登记在链上：别人给你发消息时，从链上查到你的 DOCK，才知道往哪里送；
- 在应用里一键把当前服务器登记为自己的 DOCK 和 DISK，并等到清单打勾。

## 准备

- 演示设备：专用演示手机，飞人 Android 3.3.1，接着 U1-05（已注册 CID Tom_9yw4，"设置链上服务器"展开）
- 演示身份：Tom_9yw4（FLZSnb5…y9yw4）
- 前置状态：已有 FCH；区块高度未到 4,000,000，不需要币天
- 安全：本集不涉及私钥。登记会付一笔手续费

## 核对依据

- 清单第四项"设置链上服务器"（`gs_step_set_home`），按钮"设置"（`gs_action_set_home`）；说明 `gs_explain_set_home`："链上服务器告诉别人去哪里找你。DOCK在你离线时替你保存消息，DISK保存你的文件。它们在链上登记之前，别人无处联系你。"
- 链上同时登记了 DOCK 和 DISK 才打勾：`Onboarding`，`HomeFeip.declares`
- 点"设置"弹出对话框（`ChannelSetupDialog`）：当前服务器带 DISK 时显示"将当前服务器同时用于消息（DOCK）和数据（DISK）吗？"，下面"服务器 SID："和一串 SID；按钮"使用当前服务器""高级设置…""暂不"
- "发送交易"页"上链中"一行旁有 JSON 图标，点开弹出标题"上链中"的格式化 JSON（`SendTxActivity` `showJsonDialog`，`JsonUtils.strToNiceJson`）
- 中文名用应用界面的叫法：消息服务器（DOCK）、链服务器（BASE）（`server_setup_*_label`）；DISK 界面写作"数据服务器（DISK）"，旁白改叫"文件服务器"，因为消息、语音也是数据（用户定）。应用中文界面已同步改为"文件"（Freer 源码 2026-10-15，未发布；本集录屏仍是旧字样"数据（DISK）"）；CALL 界面写作"CALL（语音通话）"，旁白按同一格式叫"通话服务器"（用户定）
- 点"使用当前服务器"后进入"发送交易"页，可看到交易费、币天销毁和上链内容，点发送按钮才广播（用户实机核实，2026-10-15）。发送后提示"交易已发送，需1–5分钟确认"（`tx_sent`）
- "高级设置…"打开"设置链上服务器"页，可分别填链服务器（BASE）、消息服务器（DOCK）、数据服务器（DISK），以及 CALL、ROAD、FUDP（`ServerSetupActivity`）。本集只提一句，不录
- BASE 提供链上数据基础服务，登录时已接入默认 BASE 服务器；CALL 用于实时语音通话和语音会议，会暴露个人语音特征，默认不开通（`server_setup_call_explain`）。两者都在"高级设置"里，本集只提一句（用户提供）
- 上链的是 FEIP9 Home：一张"名称→服务"的表，register 会整张替换；应用先读链上现有的表再合并，不会抹掉别的项（`HomeFeip.merged`）
- DOCK 明文登记；DISK 默认加密给自己的公钥，只有自己能读（`HomeEdits.diskPrivate = true`，`HomePrivacy`）。"发送交易"页的上链内容里，DOCK 是服务 ID，DISK 是一串密文（录屏时确认）
- DISK 是自己保存文件的地方，所以登记可以加密。别人给你发文件：用收件人的公钥加密，存在发送人指定的 DISK 服务上，通过消息告诉收件人去取（用户提供）
- DOCK：发送方把数据放进收件人的 DOCK，收件人稍后来取；存放有期限，到期清除；单条最大 64 KB，大的数据应放 DISK，DOCK 里只传它的 DID：FAPI13 §1、§2.2
- DISK：按内容寻址保存文件，可限期或永久保存：FAPI12
- 服务器本身也在链上登记为服务，SID 是它的服务 ID
- 没有 DOCK 时聊天是"只发模式"：可以发但收不到回复（`im_send_only_no_dock`）
- 广播后清单显示"等待上链确认"（`gs_status_pending`），确认后才打勾（`Onboarding.carveStep`）；U1-05 录制时需点刷新才更新

## 场景

### S1 [讲师] 开场

> 上一集，你有了名字，别人也能给你发加密消息了。
> 可手机不会一直在线。你不在的时候，消息送到哪里呢？
> 这一集，我们在链上登记自己的服务器。

### S2 [动画] DOCK 和 DISK

标注：左边发信人，右边你的手机（灰色，离线）；发信人先查链，链上记录里亮出"DOCK"一行；消息飞进 DOCK 存着，带一个倒计时；你的手机亮起，从 DOCK 取走消息；你自己的文件放进你的 DISK；发信人把加了锁的文件放进另一个 DISK，再通过 DOCK 送来一张"去这里取"的小纸条，你的手机去取回；最后链上记录：DOCK 一行明文，DISK 一行上锁

> 飞人里，通过各种服务商获得网络相关服务。
> DOCK 是消息服务器。别人给你的消息，先放进你的 DOCK，等你上线了再来取。
> DISK 是文件服务器，保存你的文件。大的文件放在 DISK，消息只负责告诉对方去哪里取。
> 别人怎么知道你的 DOCK 在哪里？看链上的登记。
> 没有这份登记，别人的消息就无处可送。
> 你的 DOCK 是公开的，谁都能查到。
> DISK 的登记默认加密，只有你自己能读，别人不知道你的DISK服务商是谁。
> 如果别人发文件给你，会通过消息告诉你，到哪个DISK服务读取。

### S3 [录屏] 一键设置

操作：主页"设置链上服务器"展开，有"设置"按钮 → 停留，让说明可读 → 点"设置" → 弹出对话框，停留三秒，让问题和服务器 SID 可读 → 点"使用当前服务器" → 进入"发送交易"页，停留，让交易费可读 → 点"上链中"一行旁的 JSON 图标 → 弹出格式化的 JSON，停留三秒，让 DOCK 和 DISK 两行可读 → 关闭 → 点发送按钮 → 提示"交易已发送" → 回到主页，清单显示"等待上链确认"，停留三秒 →（等一个区块后，没有自动更新）点身份卡片上的刷新按钮 → "设置链上服务器"打勾，停留三秒

### S4 [卡片] 要点

- DOCK：消息服务器，你不在线时替你暂存消息
- DISK：文件服务器，保存你的文件
- 在链上声明自己的DOCK，别人才能给你发信息
- 所有服务商都登记在链上，不满意就换

> 记住这四点。
