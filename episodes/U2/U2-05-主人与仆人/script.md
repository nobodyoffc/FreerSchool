## 目标

看完这一集，观众能够：
- 知道"设置主人"是什么：把自己的私钥用主人的公钥加密，连同"主人拥有我的一切权利"的承诺刻上链；只有主人能解开；一个 FID 只能设一次，不能更改、不能撤销；
- 会设置主人：设置 →"设置主人"→ 搜索主人 → 选中 → 确认上链；
- 知道主人该选谁：主人的私钥一旦泄露，仆人也跟着泄露，所以主人的安全级别要高于仆人，私钥最好离线保存；
- 知道主仆关系的意义：关系公开在链上，仆人无法抵赖；主人可以在仆人私钥泄露时保护仆人的链下权益；声明是仆人单向发出的，对主人没有约束力；
- 在主人身份下用"我的仆人"从链上找回仆人，点一下就能切换过去查看。

本集独立成篇，不承前启后。

## 核对依据

- 协议 FEIP6（`~/Freeverse/Protocols/FEIP/FEIP6V1_Master.md`）：数据含 `master`（主人 FID）和固定承诺 `promise` = "The master owns all my rights."，可附 `cipherPriKey`（用主人公钥加密的签名者私钥）。一次写入：签名者已有主人，再设一律忽略（手续费照付）。私钥密文只记在历史记录里。协议只有签名者一方签名，主人不参与
- 飞人加密方式：用主人的公钥单向加密主身份的私钥（`FeipHandler.masterSet`，`FC_EccK1AesGcm256`），所以**主人必须有公钥**：搜到的身份公钥要已上链，或直接输入主人的公钥（`SetMasterActivity.performSearch` 识别公钥输入）
- 入口一：主页齿轮"设置"菜单 →"设置主人"（`popup_menu_settings.xml`）。只在当前是主身份、链上还没有主人、也没有正在上链的设置主人交易时显示（`PopupMenuHelper.hasNoMasterYet`）；设过以后这一项消失
- 入口二：身份菜单 →"我的主人"：没有主人时弹窗问是否设置（3.3.1 里弹窗是英文："Set Master"/"No master is set for this FID. Would you like to set a master?"）；已有主人则切换到主人身份（本机没有就从网络取）
- 入口三：备份私钥对话框里也有"设置主人"按钮（`BackupPrikeyDialog.showMasterSection`），说明文字："设置主人，会把这把钥匙加密给另一个FID的公钥后刻上链，那个FID便能还原它。此举永久生效，需付手续费，并把这个身份的一切权利都交给对方——只把主人设给你完全信任的、自己的FID。"
- "设置主人"页（`SetMasterActivity`，`activity_set_master.xml`）：上方"当前身份:"卡片；"搜索主人"输入框，提示"输入主人FID或姓名"；底部是图标按钮：搜索（放大镜）、清除、确认（发送图标）、返回。输入 FID 精确查，输入名字按 CID 模糊查；点结果卡片选中，提示"主人已选择"，发送图标才可点
- 确认：主人若是明人，先弹明人警告（`NobodyGuard`，"设置主人会把你的私钥加密给主人后公开上链。任何人都能解密它，从而永久接管这个身份。"）；再查链上是否已有主人（有则拒绝："链上记录显示这个FID的主人已经是 %s……"）；然后"确认设置主人"对话框："将%s设置为%s的主人？这将把私钥加密上链。主人可以解密该私钥。此操作是永久的：按FEIP6，一个FID只能设置一次主人，之后无法更改或撤销。"（按钮"中止""否""是"）→ 成功提示"主人设置成功！交易ID: …"
- 主人取回仆人私钥：协议上主人用自己的私钥解密 `cipherPriKey` 即可。飞人里的"来自主密钥"菜单（`AddPrikeyPopupMenuHelper.handleFromMaster`）在 3.3.1 中入口被注释掉（`HomeActivity.setMultisignIconListener`），**本集不演示取回，只在旁白里说"主人能解开"**
- 身份菜单（`popup_menu_person.xml`）：顶部"当前活跃身份"一栏实际显示英文"Living: Main FID / Master / Servant"（`PersonPopupMenuHelper.setupPopupContent`）；下面"主身份""我的主人""观察名单""我的多签""我的仆人""退出主身份"。当前是主身份时"主身份"变灰；当前不是主身份时"我的主人""我的仆人"等变灰，只能点"主身份"切回（不弹确认，直接切换，提示"切换身份成功"）
- 我的仆人：身份菜单 →"我的仆人"→"选择仆人FID"页（空时显示"没有可用的仆人"），底部图标：添加（加号）、返回 → 点添加 →"添加仆人FID"页，自动从链上查出以当前身份为主人的 FID（`fapiClient.myServants`），列在"我的仆人"下，可勾"全部"；底部图标：刷新、添加（对勾）、返回 → 选中后点对勾，提示"仆人FID添加成功" → 回到列表，点仆人卡片即切换过去（"切换FID中"）。卡片菜单可删除（只从本机列表去掉）
- 仆人身份在主人的手机上没有私钥：切换过去只能看；要付款时飞人只生成未签名交易（"没有私钥。复制去签名并广播。"`TxSender` 的 `onUnsignedTx`）。本集不讲

## 场景

### S1 [讲师] 开场

> 一个身份可以声明另一个身份作为自己的主人。
> 主人可以保管仆人的私钥，行使仆人的一切权利。

### S2 [动画] 设置主人是什么

标注：每句一步——①左边仆人身份卡片，右边主人身份卡片；②仆人的私钥（钥匙图标）被主人的公钥（锁）锁进一个盒子；③盒子连同一行承诺"主人拥有我的一切权利"刻进链上的一个区块；④只有主人的私钥能打开盒子，钥匙回到主人手里；⑤盒子上盖章"仅此一次，永不撤销"

> 设置主人，就是一个身份宣布：另一个身份是我的主人。
> 并且把自己的私钥，用主人的公钥加密。
> 再连同一句承诺，主人拥有我的一切权利，一起刻在链上。
> 这份密文只有主人的私钥能解开，主人随时可以取回仆人的私钥，所以，这是基于完全信任的社交备份。
> 一个身份只能设一次主人，设了以后，不能更改，也不能撤销。

### S4 [讲师] 主人该选谁

> 设置主人，相当于把私钥备份在链上，只有主人打得开。
> 手机丢了，或者备份找不到了，主人还能把这个身份找回来。
> 但反过来，主人的私钥一旦泄露，仆人的私钥也就跟着泄露了。
> 所以，主人的安全级别一定要比仆人高，建议私钥离线保存。

### S5 [动画] 主人的意义

标注：每句一步——①链上区块里的主仆声明亮起，四周一圈人都看得见，盖章"公开"；②仆人的钥匙被偷走（小偷剪影），主人身份挡在仆人前面；③服务商图标：仆人签名的请求被拒，服务转到主人指定的新身份名下；④引路人卡片标"母亲"、主人卡片标"父亲"，与仆人连线；⑤主人卡片放大，压过引路人；⑥声明的箭头只从仆人指向主人，主人一侧没有签名

> 主仆关系是链上公开的，是故意告诉所有人的，仆人无法抵赖。
> 基于链上生命，主人的权力超越仆人。所以，主人可以在仆人私钥泄露时，保护仆人链下权益。
> 比如，主人可以要求服务商无视仆人的签名，将仆人购买的服务转到另一个身份名下。
> 如果说引路人像带来生命的母亲，主人就像亲自声明的父亲。
> 主人是比引路人更重要的社会关系。
> 特别注意：主人声明是仆人单向发出的。主人并未签名确认这个关系。因此，声明对主人没有任何约束力。
