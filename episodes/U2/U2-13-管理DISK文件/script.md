## 目标

看完这一集，观众能够：
- 知道飞人把文件加密后存在 DISK 上：DISK 只保存看不懂的密文，打开它的钥匙用你的公钥加密，记在一条 HAT 里；
- 会在"数据"里添加文件、上传到 DISK；
- 会移除本地数据腾出手机空间，需要时再从 DISK 下载、打开；
- 知道 HAT 只在这部手机上，要用"导出HAT"备份，换手机时导入 HAT，再从 DISK 下载文件。

本集独立成篇，不承前启后。

## 准备

- 演示设备：专用演示手机，飞人 Android 3.3.1
- 演示身份（只写 FID，不写私钥）：
  - 主身份：Tom_9yw4 `FLZSnb5uRFzz9jSiaNyWnpLfHjuMNy9yw4`，已登记 DISK（见 U1-06），有少量 FCH 付 DISK 的费用
- 前置状态：飞人停在主页，当前身份是 Tom_9yw4；"数据"里为空或只有演示文件
- 演示文件：手机相册里事先放一张不含任何私人信息的图片（如一张风景照，文件名如"山顶.jpg"），录完可删
- 上传、下载各发生一次，DISK 服务会收取少量费用

## 核对依据

- 入口：主页"数据"（`menu_data` → `DataActivity`，标题"数据"）。只对主身份开放（附属身份提示"数据仅对主 FID 可用，主 FID 持有用于加密的私钥。"）；没有 DISK 时提示先设置
- "数据"页（`DataActivity`）：顶部搜索框，排序"时间""姓名""大小"（**"姓名"应为"名称"**，`name` 这条文字被多处共用——建议应用里另设一条）；每张卡片（`HatCardContainer`）显示类型图标、名称、ID（前后各 8 位）、大小、时间，右侧存储位置图标和播放图标（"打开"），复选框常显示；底部统计"显示 N / 共 M"；底部按钮：更多、上传、下载、添加、返回；"全部"复选框
  - 存储位置图标：只在本机 `ic_local`（"本地存储"）、只在 DISK `ic_disk`（"存储在 DISK"）、两处都有 `ic_disk_local`（"存储在 DISK 与本地"）
  - 点卡片打开 HAT 详情；点播放图标打开文件：本机没有就先从 DISK 下载（要私钥解密），再用手机上的应用打开（`HatFileOpener`）
- 添加（`addNewFile`）：系统文件选择器，可多选；文件复制进飞人自己的目录，ID 是文件内容的双重 SHA256（DID），生成一条 HAT（名称、大小、类型、时间、位置 `local://`）；提示"文件添加成功"。只在本机，没有上传
- 上传（`launchUploadDataActivity` → "上传数据"页 → `UploadService`）：只对勾选的、只在本机的文件；上传页列出这些文件，点"上传"图标开始，回到"数据"页显示进度条，完成提示"上传完成：已上传 N，已跳过 N，失败 N"；DISK 上已有的跳过
  - 加密（`DataSyncManager.uploadData`，两条 HAT）：随机生成对称密钥，把文件加密成密文；密钥用当前身份的公钥加密（`kCipher`）；只把密文传到 DISK；原文件的 HAT 记下密文的 ID（`cipherIds`），密文的 HAT 记下 DISK 位置和加密后的密钥。DISK 拿不到原文，也拿不到密钥
  - 上传是长期保存（`permanent = true`）；DISK 收费（通知里显示"费用：N sats"）
- "更多"菜单（`popup_data_menu`）："导入HAT""导出HAT""移除本地数据""删除数据"
  - 移除本地数据：对勾选的、本机有文件的；确认框"移除 N 个已选HAT的本地数据？本地文件将被永久删除。HAT记录将保留并更新其位置信息。"；之后卡片变成只在 DISK
  - 删除数据：删除本地文件和 HAT 记录，"此操作无法撤消"（本集不演示）
- 下载（`launchDownloadDataActivity` → "下载数据"页 → `DownloadService`）：只对勾选的、本机没有文件但 DISK 上有的；下载密文，用私钥解开密钥，再解密成原文件，存回飞人目录；完成提示"下载完成：已下载 N，失败 N"。中途取消提示"已接收的数据将被丢弃，重新下载将再次计费"
- 导出HAT（`ExportHatActivity`，"导出HAT"）：把 HAT 列表导出为 JSON，**不加密**，存到手机下载目录（`hats_<FID>_<时间>.json`），也可转二维码、复制。里面有文件名、大小、DISK 位置和用公钥加密过的密钥——没有私钥打不开文件，但文件名等信息是明文
- 导入HAT（`ImportHatActivity`）：粘贴、选文件或扫码，把 HAT 加回列表；之后勾选下载即可
- HAT（FVEP10，Hash Attribute Table）：描述一份数据的记录，DID 是唯一联系；DISK 只管按 DID 存取字节，不懂含义。"HAT 很小，传递的是 HAT，不是数据"
- 换 DISK：下载时按 HAT 里记的位置（`fudp://…` 或 `(sid)…`）连接对应的 DISK，不一定是当前登记的那个（`DataSyncManager.getFapiClientForLoca`）；界面上没有"同一文件存多个 DISK"的操作
- **集目里的"同步"在应用里没有入口**：`SyncResultDialog` 没有被调用，定时备份 HAT 的 `HatBackupWorker` 没有被启用。本集只讲手动的上传、下载、导出导入 HAT
- 读音（`READINGS`，字幕保留原文）：DISK 按 U1-06 的读法；HAT 逐字母读；合成前跑 `readings.py`

## 场景

### S1 [讲师] 开场

> 照片、合同、视频，这些文件你存在哪里？
> 只放在手机上，手机丢了就没了；放在网盘上，平台能看，也能关。
> 飞人把文件加密后，存在你自己选的 DISK 服务器上。

### S2 [动画] 文件怎样存进 DISK

标注：动画 DiskHat。每句一步——①一张图片"山顶.jpg"在手机里；②一把随机生成的钥匙把图片锁成一团乱码"密文"，只有密文飞向右边的 DISK 服务器；③DISK 里一格格编号的乱码，旁边一个问号脸，"只存字节，看不懂"；④钥匙本身被 Tom 的公钥锁进一个小盒子，和"山顶.jpg、2.1 MB、DISK 位置"一起写进一张卡片"HAT"，卡片留在手机里；⑤新手机：拿着 HAT 和私钥，打开小盒子取出钥匙，从 DISK 取回密文解开，图片重现；⑥旧手机里的 HAT 复制一份成为"备份"文件

> 在飞人里添加一个文件，它先只保存在手机上。
> 上传时，飞人用一把随机生成的密钥把文件加密，只把密文传到 DISK。
> DISK 只保存这串看不懂的密文。
> 那把密钥再用你的公钥加密，和文件名、大小、存放位置一起，记在手机里的一条记录上，叫 HAT。
> 有了 HAT 和你的私钥，在任何手机上都能从 DISK 取回文件，解密打开。
> 所以，HAT 也要备份。

### S3 [录屏] 添加并上传

操作：主页 → 点"数据" → "数据"页（空或只有演示文件），停 1 秒 → 点"添加" → 系统文件选择器，选相册里的"山顶.jpg" → 回到"数据"页，提示"文件添加成功"，新卡片显示本地图标，停 2 秒 → 勾选这张卡片 → 点"上传" → "上传数据"页列出这个文件，停 1 秒 → 点"上传"图标 → 回到"数据"页，进度条走完，提示"上传完成：已上传 1……"，卡片图标变为 DISK 与本地，停 2 秒
注意：文件选择器里不要露出相册的其他照片（录前清空或只留演示图片）

> 在主页点数据，再点添加，选一个文件。
> 卡片上的这个图标，表示它只在本机。
> 勾选它，点上传，再点上传图标。
> 上传完成，图标变成了 DISK 加本地，说明两处都有。

### S4 [录屏] 腾出空间，再下载回来

操作：在"数据"页勾选"山顶.jpg" → 点"更多" → 菜单停 1 秒 → 点"移除本地数据" → 确认框停 1 秒 → 点"确定" → 卡片图标变为只在 DISK，停 2 秒 → 勾选 → 点"下载" → "下载数据"页，点"下载"图标 → 回到"数据"页，进度条走完，提示"下载完成：已下载 1……"，图标变回 DISK 与本地 → 点卡片的播放图标 → 用相册打开图片，停 2 秒 → 返回

> 手机空间不够时，勾选文件，点更多，选移除本地数据。
> 手机上的文件删掉了，HAT 还在，图标变成只在 DISK。
> 要用的时候，勾选它，点下载，飞人从 DISK 取回密文，用你的私钥解密。
> 点播放图标，就能打开。本机没有的文件，点播放图标也会先自动下载。

### S5 [录屏] 备份 HAT

操作：在"数据"页点"更多" → 点"导出HAT" → "导出HAT"页，点导出图标 → 提示文件已保存到下载目录（hats_….json），停 2 秒 → 返回 → 点"更多"，停在"导入HAT"上 1 秒 → 收起菜单
注意：导出的 JSON 里有 Tom 的 FID 和文件名，不含私钥；画面上可以出现

> HAT 只保存在这部手机上。点更多，选导出HAT，把它们存成一个文件。
> 换了手机，用同一个身份登录，在这里导入HAT，再勾选下载，文件就都回来了。
> 导出的 HAT 里，文件名是明文，但打开文件的密钥是加密的，没有你的私钥，谁也打不开文件。

### S6 [讲师] 结尾

> DISK 只替你保管密文，钥匙始终在你手里。
> HAT 记着每个文件存在哪个 DISK 上，以后换了 DISK，以前的文件照样能取回。
> 文件属于你，而不是属于哪个平台。

### S7 [卡片] 要点

- 上传前文件被加密，DISK 只保存密文
- 打开文件的密钥用你的公钥加密，记在 HAT 里
- 移除本地数据腾出空间，需要时再下载
- HAT 只在本机，要导出备份

> 记住这四点。
