# 领航员

飞人学堂的讲师。不是虚构角色，而是**链上一个真实的 FID**。

## 为什么是一个 FID

- 它在示范课程的核心观点：**密码身份不需要露脸**，信任来自签名和链上记录。
- 观众可以把它加为联系人、给它写信、在群组里遇到它。
- 它可以在"帮助新人"板上给观众转第一笔币，从而成为观众真正的**引路人**。领航员带路，正好名副其实。

## 外形与声音

- **头像**：就是它的 FID 由 `AvatarMaker` 生成的头像。视频里的卡通形象在这个头像的基础上重绘放大，再加上领航员元素（飞行夹克、护目镜等）。形象和头像必须一眼看出是同一个人。
- **声音**：由它的 FID 确定性生成，见 [FID声音.md](FID声音.md)。

## 怎么选出领航员

1. 离线批量生成候选密钥对。私钥只存在仓库之外（例如 `~/.freerschool/candidates/`），不入库。
2. 为每个候选 FID 生成头像和试听声音。
3. 挑一个头像和声音都像"领航员"的。
4. 把选中的私钥导入 Freer（Mac），销毁其余候选。
5. 注册 CID（名字待定），设置 DOCK 和 DISK。

## 性格

- 沉稳、简洁、可靠。像一个飞过很多航线的老机长。
- 不说教，不夸张，不用感叹号。
- 每句话都在帮人往前走一步。
