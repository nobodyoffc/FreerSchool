# FID 声音（设计草案）

像 `AvatarMaker` 为每个 FID 生成唯一头像那样，为每个 FID 生成唯一的声音。

## 要求

1. **确定性**：同一个 FID，永远得到同一个声音。
2. **可复现**：任何人拿到 FID，用公开的算法和模型，都能独立生成同一个声音，不依赖任何平台账号或 API。
3. **分布均匀**：不同的 FID 声音差异明显，并且每个结果都是"能听"的正常人声。
4. **有版本**：算法和模型权重一旦发布就固定，改动就升一个版本号。

## 一个必须讲清楚的边界

**声音和头像一样，只是装饰，不是认证。** FID 是公开的，所以任何人都能生成任何 FID 的声音。能证明"这段话确实出自这个 FID"的，只有签名。

这一点本身就可以成为一集的内容。

## 推导方法

```
seed = SHA256("FreerVoice/v1/" + FID)

字节   参数
0–1    基础音色 A：在 N 个固定的基础说话人中选一个
2–3    基础音色 B：另选一个
4      混合比例 w ∈ [0.2, 0.8]       → 音色 = slerp(A, B, w)
5      音高偏移 ∈ [-2, +2] 半音
6      语速 ∈ [0.92, 1.08]
7      能量（音量起伏）∈ [0.9, 1.1]
8–15   合成时用的随机种子
```

- 用哈希而不是像 `AvatarMaker` 那样直接取地址的字符位置：哈希的分布更均匀，也方便加版本前缀。
- 基础说话人的列表和模型权重的 SHA256 都写进规范，作为"FreerVoice v1"的一部分。
- 参数范围要收窄，确保每个结果都是自然的人声，而不是怪声。

## 引擎候选

要求能**在本地运行**、**可以混合音色向量**，并且中文质量足够好。

| 引擎 | 音色混合 | 中文质量 | 本地运行（M2 Pro） | 评价 |
|---|---|---|---|---|
| **Kokoro-82M** | 风格向量可直接线性混合，已被广泛验证 | 一般，中文基础音色少 | 很快，CPU 即可 | 适合先验证思路 |
| **CosyVoice 2/3** | 说话人嵌入可以插值，需要实测效果 | 很好 | 可以，速度中等 | 质量最有希望 |
| MiniMax 等商业 API | 用文字描述设计声音 | 很好 | 否 | **不满足可复现**，只作备用 |

## 计划

1. 用 Kokoro 做原型：10 个 FID → 10 段试听，验证"确定性 + 区分度"。
2. 用 CosyVoice 做同样的测试，比较中文质量。
3. 选定引擎后写成规范 `FreerVoice v1`，并实现为 `voice/` 下的命令行工具：

   ```bash
   freer-voice --fid <FID> --text "你好，我是领航员" --out hello.wav
   ```
4. 以后可以考虑把它提为 Freeverse 的协议，在 FC-JDK 和 Freer App 里实现。比如在 Talk 里朗读消息时，用发送者的 FID 声音来读。
