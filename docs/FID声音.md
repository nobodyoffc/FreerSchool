# FID 声音（设计草案）

像 `AvatarMaker` 为每个 FID 生成唯一头像那样，为每个 FID 生成唯一的声音。

## 要求

1. **确定性**：同一个 FID，永远得到同一个声音。
2. **可复现**：任何人拿到 FID，用公开的算法和模型，都能独立生成同一个声音，不依赖任何平台账号或 API。
3. **分布均匀**：不同的 FID 声音差异明显，并且每个结果都是"能听"的正常人声。
4. **有版本**：算法和模型权重一旦发布就固定，改动就升一个版本号。

## 一个必须讲清楚的边界

**声音和头像一样，只是装饰，不是认证。** FID 是公开的，所以任何人都能生成任何 FID 的声音。能证明"这段话确实出自这个 FID"的，只有签名。

这一点本身就可以成为一集的内容。

## 推导方法（v1，已实现于 `voice/freer_voice.py`）

```
h = SHA256("FreerVoice/v1/" + FID)

字节     参数
0        性别：偶数 → 女声（zf_*），奇数 → 男声（zm_*）
1–2      音色 A：从该性别的音色列表中选一个（主音色）
3–4      音色 B：同一列表中除 A 以外另选一个
5        B 的占比 w ∈ [0, 0.3]；风格 = (1-w)·A + w·B
8        音高 ∈ [-3, +3] 半音
9        语速 ∈ [0.9, 1.1]
16–23    声码器噪声的随机种子

最后：风格 += 0.3 × (风格 − 该性别全部基础音色的平均)
选中排除名单里的音色时：用 SHA256(h ‖ 字节位置 ‖ n) 重新抽，n = 0, 1, …
```

- **以一个音色为主**：v0 让两个音色按 20%–80% 混合，个性被平均掉了。
- **音高在模型内部调**：缩放预测出的音高曲线，再送入声码器。只改音高，不改音色，也没有事后变调造成的失真。
- **夸张化 0.3**：把声音往远离同性别平均声音的方向推。0.3 时差异度与真人音色之间的天然差异相当；更大的值耳朵听不出更多区别。
- **韵律不另取**：曾尝试让音色和韵律（风格向量后 128 维，决定声调走势）取自不同音色，结果发现部分基础音色的韵律本身带"外国腔"，借过来会让声调走样，所以去掉了。
- **排除名单 `EXCLUDED`**：声调怪异的基础音色永不选用。选中时用哈希重新抽，所以**以后再排除某个音色，只影响恰好选中它的 FID**，其余 FID 的声音不变。用 `voice/screen_voices.py` 生成筛选页，人工试听后加入名单。
- **只在同性别内混合**：跨性别混合容易出现不自然的声音。
- 先校验 FID（Base58Check，版本字节 0x23），不合法的字符串不生成声音。
- 模型的仓库版本、权重 SHA256、夸张度、排除名单都固定在代码里，是规范的一部分。
- 版本号参与哈希，所以**换版本后同一个 FID 的声音会整个改变**，性别也可能变。

## 引擎候选

要求能**在本地运行**、**可以混合音色向量**，并且中文质量足够好。

| 引擎 | 音色混合 | 中文质量 | 本地运行（M2 Pro） | 评价 |
|---|---|---|---|---|
| **Kokoro-82M** | 风格向量可直接混合；音色与韵律可分开 | 中等；v1.1-zh 有 100 个中文基础音色（55 女 45 男） | 很快，CPU 即可 | 已做原型 |
| **CosyVoice 2/3** | 说话人嵌入可以插值，需要实测效果 | 很好 | 可以，速度中等 | 质量最有希望 |
| MiniMax 等商业 API | 用文字描述设计声音 | 很好 | 否 | **不满足可复现**，只作备用 |

## 测试结果（2026-10-11，Kokoro v1.1-zh）

- **确定性** ✔：同一个 FID 两次合成的音频逐字节相同。
- **性别比例** ✔：一万个 FID 中女 5075、男 4925。
- **中英混读** ✔：英文单词交给英文发音模块处理；术语表 `LEXICON` 可以覆盖默认读法（例如 FID 逐个字母读）。
- **速度** ✔：M2 Pro 只用 CPU，合成一句话连同加载模型约 35 秒，模型加载好之后再合成要快得多。
- **差异度**：用声纹识别模型 ECAPA 测量同性别声音两两之间的平均相似度，越低越容易区分（`voice/compare.py`，30 个 FID）：

  | | 女声 | 男声 |
  |---|---|---|
  | 100 个原始音色（天然差异参照） | 0.48 | 0.44 |
  | v0 | 0.63 | 0.65 |
  | **v1** | **0.47** | **0.42** |

  试听结论：v1 比 v0 区别明显；夸张度在 0.3–1.0 之间，耳朵听不出太大区别。
- **声调问题**：男声里"员""单"曾像外国人念中文。逐项排查后确认，原因是借用了 zm_062 的韵律，而这个基础音色本身就带怪腔。已去掉韵律另取。
- **基础音色筛选**（2026-10-11，人工试听"我是领航员。主页上有一份新手入门清单，我们一项一项完成它。"）：
  - "员""单"都变调，**已排除**（11 个）：zm_010、013、014、016、030、035、058、062、068；zf_060、090。
  - 只有句末的"员"由第二声变成第三声（像"远"），**暂时保留**（49 个）：zm_015、025、029、033、034、037、041、045、050、055、057、061、063、065、066、069、080、082、091；zf_003、004、005、007、008、017、021、022、023、024、026、027、028、032、036、040、046、047、067、070、071、072、074、078、079、085、092、094、099。
    这么多音色出同一个问题，更像是模型对句末"员"的处理有局限，而不是这些音色本身有问题。写脚本时，领航员的声音（zm_053 为主）不受影响；对比 CosyVoice 时再看能否解决。
  - 尝试过用音高曲线自动检测"员"的声调，与人工标注的吻合度只有约 60%，不可用。
- **领航员** `FQ8KKsMFYXkmNPDVauEMWFBnd7yfhiqqN8`：男声；zm_053 为主（0.91）、zm_098 为辅（0.09）；音高 −0.6 半音；语速 0.989。
