## 使用 · 入门（U1）— Android

**目标**：一个从没接触过飞人的人看完本季，拥有一个有名字、能收发消息、有引路人、加入了群组的密码身份，并能反过来帮助下一个新人。

主线即应用内置的新手清单（`OnboardingStep`）：备份私钥 → 获得第一张钞票 → 注册CID → 设置DOCK和DISK → 把引路人加为联系人 → 加入一个群组。
