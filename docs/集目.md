## 使用 · 入门（U1）— Android

**目标**：一个从没接触过飞人的人看完本季，拥有一个有名字、能收发消息、有引路人、加入了广场的密码身份，并能反过来帮助下一个新人。

主线即应用内置的新手清单（`OnboardingStep`）：备份私钥 → 获得第一张钞票 → 注册CID → 设置DOCK和DISK → 把引路人加为联系人 → 加入一个广场。

## 使用 · 进阶（U2）— Android

本季起各集独立成篇，可以不按顺序看。

**目标**：学完本季，能把私钥放到更安全的地方，按用途分出多个身份并给它们分好工，用好飞人的交易、存储、群组和链上数据功能。

密库（Safe）是单独的应用，专管私钥，可离线使用；飞人负责联网。本季前半段讲两者配合。录屏里私钥、密语等敏感内容一律用已公开私钥的明人身份展示。
