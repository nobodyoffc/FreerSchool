# 制作原则

1. **简洁实用，效率优先**。每集 2–5 分钟，一集只讲一件事。
2. **先做后讲**。入门阶段让观众先动手，道理放在"懂"线里讲，两边互相引用。
3. **三线三级**。用、懂、建三条线，各分入门、进阶、专业三级。入门求快速上手，进阶补充细节和更多功能，专业深入底层。
4. **讲的与应用一致**。术语用应用中文界面的叫法；每段录屏注明应用版本。
5. **安全示范**。只用演示身份；镜头里的每个动作都是值得模仿的安全习惯。
6. **链上可验证**。演示产生的交易、CID、信件都真实上链，观众可以自己查。
7. **作业在链上**。练习就是链上行为：创建身份、注册 CID、给领航员写信、加入群组。
8. **文本为源**。脚本是唯一源头，视频是构建产物，可以复现、修改和翻译。
9. **不露脸，不用真声**。讲师是一个链上 FID——领航员。这本身也在示范密码身份。
10. **先中文，后英文**；**先 Android，后以 Mac 为重**。Android 集用竖屏（1080×1920），Mac 集用横屏（1920×1080），由脚本的 `app` 字段决定。
